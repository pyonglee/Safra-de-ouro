# Safra de Ouro — Project Instructions

## Overview
Coffee farm management app for Brazilian rural producers. All UI in pt-BR.

## Theme
- Primary Brown: #6B4226
- Accent Gold: #D4A017
- Success Green: #2E7D32
- Error Red: #C62828
- Background: #FAF6F1
- Surface: #FFFFFF
- Secondary Surface: #F5EFE6
- Text Primary: #3E2723
- Text Secondary: #795548

## Navigation
- Auth group: /auth/login, /auth/signup
- Tabs group: /tabs (5 tabs: Painel, Trabalhadores, Despesas, Produção, Mais)
- Stack screens outside tabs for detail/add screens

## API
- Base URL: EXPO_PUBLIC_API_URL env var
- Auth: Bearer token in headers
- POST /api/signup, POST /api/auth/login, GET /api/auth/me
- CRUD: /api/workers, /api/harvests, /api/balaio-records, /api/production-records, /api/expenses, /api/quotations
- GET/PATCH /api/settings
- GET /api/dashboard?harvestId=UUID
- GET /api/reports/{expenses,workers,production,profit}

## Formatting
- Currency: R$ with Brazilian format (dot thousands, comma decimals)
- Dates: dd/MM/yyyy
